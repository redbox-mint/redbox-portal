# Default portal fonts

Unmodified WOFF2 subsets served by Google Fonts, downloaded 2026-11-07.
Each family is licensed under SIL Open Font License 1.1; the family-specific OFL files include copyright notices.
No font names or outlines have been modified.

The original public weights are retained: Titillium Web 200/300/400/600/700, Roboto Condensed 300/400/700, Raleway 100/400. All returned language subsets are retained. `font-display: swap` and Unicode ranges match the upstream CSS.

`assets/default/default/styles/default-fonts.css` declares these faces in the main bundle. Preloads use the same content-versioned Latin faces. Custom brand typefaces continue to override via theme CSS variables and retain their own preload.
