# Branding typeface test fixtures

Synthesized minimal WOFF2 containers generated by `generate-fixtures.js`
(`node test/resources/fonts/generate-fixtures.js`). They carry a structurally
valid container (header plus table directory) with deterministic filler bytes
instead of real outlines, so they exercise upload validation, content
addressing, publication, and public delivery without any third-party font
bytes. No licence record is required.

| File | Content |
|---|---|
| `test-font-regular.woff2` | Valid static WOFF2 |
| `test-font-bold.woff2` | Valid static WOFF2 with distinct bytes |
| `test-font-italic.woff2` | Valid static WOFF2 with distinct bytes |
| `test-font-variable.woff2` | Structurally valid variable WOFF2 (`fvar` table, must be rejected) |
| `test-font-truncated.woff2` | Truncated container (must be rejected) |
