# WSU deployment inputs — R25

The machine inventory lists **79 environment inputs** and **542 resolved configuration leaf/array inputs**, plus all CLI and build positional inputs. It records defaults, downstream values, override channels and exact source locations. Synthetic credentials used for resolution are labelled; no production configuration was read.

Precedence: core, ordered extensions, selected application, environment file, local file, canonical environment, supported CLI. Validity is checked after each layer; required hook S3 bucket/region inputs must already be valid during registration. Modules capture hook-specific environment at first import; use a fresh process after changing it. Existing brand AppConfig is dynamic and is not rewritten by startup defaults.

Only variables listed in a service environment are forwarded by Compose; other shell variables require a deployment-owned Compose override. Ports published by Compose do not change in-container service DNS/ports. Public URL and root context, listen port, cookie security/path, IdP redirect URIs, default brand/portal and page landing/logout paths are separate explicit settings. Canonical URL must contain the selected public root; the loader does not infer proxy topology or rewrite a registered IdP callback.

Every selected configuration leaf/array input is enumerated separately in [configuration-inputs.json](configuration-inputs.json). This includes Mongo driver/session policy, every queue job, Solr schema/options, authentication bootstrap data, mail transport/templates, PDF settings/options, DOI profiles and secret-provider controls. Form/workflow/metadata DSL definitions are the settled R20 domain surface, rather than deployment selectors; the default snapshot is retained in raw evidence.

AWS SDK credential sources and Nodemailer/Solr native JSON options remain provider-owned: their arbitrary nested driver keys are not invented ambient REDBOX settings. Companion provider environment is not implicitly loaded: WSU leaves it disabled unless a selected module calls the documented resolver and supplies explicit companion data. DOI URL derivation reads ambient environment before selected files/CLI and fixes the instrument brand/portal to default/rdmp; the reproduced inherited B-18 discrepancy requires explicit DOI base variables on those deployments. The two retained SAILS_DOI aliases are rejected by the canonical v6 loader; use their DOI-prefixed replacements.
