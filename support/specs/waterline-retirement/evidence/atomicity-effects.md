# P0 atomicity and effect review

Reviewed 2026-10-19 against production source `441d87304cbb820ead569a9fcab405f112de0701`. This is the implementation
assessment. Security/domain/operations agreement is **pending**, so P0.5 remains unchecked. Source behavior is
distinguished from the programme's stronger required atomic units. No transaction or recovery guarantee was added in P0.

The complete lexical transaction call list is in [inventory.json](inventory.json) (`surfaces.transaction`); precisely
four services import TransactionUtils.
[TransactionUtils](../../../../packages/redbox-core/src/utilities/TransactionUtils.ts) tries the adapter, catches its
unsupported-transaction error, then runs once without a connection. The [real capture](waterline-mongo8.ejson) proves
this path: warning, undefined connection, injected second-step failure and retained first write. This is evidence of
partial execution, never rollback evidence.

## G-TX topology prerequisite and owner record

MongoDB multi-document transactions require a **replica set or sharded cluster**. Standalone MongoDB 8.0.34/FCV 8.0
cannot qualify. The current capture and pilot standalone evidence neither prove rollback nor become transactional by
changing an adapter. See [environment and decisions](environment-release-support.md). The **operations/deployment lead**
owns the topology/support/backup decision; architecture owns supported Prisma session/routing proof; release owner owns
scope/timing and institutions approve their own deployment conversion.

Before G-TX: qualify dev/test/CI replica-set fixtures; choose institutional standalone conversion/upgrade/downtime and
rollback procedure; establish single-node replica-set support policy (transaction capability does not provide
redundancy, failover or multi-node qualification); rehearse matching topology, FCV, oplog/backup/restore and upgrade
runbooks. No replica-set stack was built in P0: standalone negative evidence is sufficient to identify this closed
prerequisite, and the chosen Prisma runtime has no transaction API anyway.

**Assessment:** no additional entire delivery group is newly classified as transaction-required. The S authorization
operation participating in U is now explicitly gated; I18n, RDMP and append-history consistency remain named owner
decisions. Approval of this matrix, precise audit boundary, recovery ownership and topology policy is outstanding. No
operational U/V/B or atomic S Prisma adapter is authorized by this assessment.
