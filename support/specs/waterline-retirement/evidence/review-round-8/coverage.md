# Cross-group parity coverage

The operation inventory is [adapter-paths.json](adapter-paths.json). It names every concrete promoted adapter entry point, source location, inherited schema operation and bounded maintenance operation. Constructor, composition and readiness work is recorded separately from domain operations. The table below applies to every inventoried path: read paths use the listed physical decoder, write paths the encoder, and criteria paths the query helper. An absent concern means that operation has no such argument or stored field, rather than an untested alternate implementation.

The shared implementation is the semantic primitive, not a generic repository. Collection/field inventories, fixed domain predicates and callback bodies remain domain-specific. Native operations retain their existing contracts; applying model defaults or coercion to them was itself a defect. Both selector choices share those native implementations.

## Helpers

- **F**: `persistence/scalars.ts#normalizePersistenceField`, calling the single pinned RTTC 10.0.1 scalar checker. One create/patch distinction, missing/default/null handling, finite scalar guard and plain JSON clone. Used by M, R, Q, J1, J2, J3 and S field encoders.
- **Q**: the same file's `coercePersistenceQueryScalar`, `persistenceQueryFields` and `persistenceStringBounds`. `NamedQueryExecution.namedQueryScalar` delegates primitive coercion to Q; its shared criteria/ordering/projection parser retains the separate native-record branch.
- **T**: `persistence/timestamps.ts#persistenceStringTimestamps`. Supplied model timestamps are coerced as strings, explicit empty/null values fail, missing values use one clock, and patches preserve caller-created timestamps. HarvestRecordEvent's required caller-owned `createdAt` uses F, not an automatic clock.
- **I**: `persistence/mongodb/identity.ts#persistenceObjectId` and `hasPersistenceObjectIdMapping`. Physical ObjectId ownership and foreign-key mappings are qualified before publication. Both create and patch encode supplied model IDs, retaining MongoDB immutable-ID refusal. Lowercase-only domain IDs and the existing uppercase cache/attachment acceptance are preserved. Opaque native IDs never pass through I.
- **P**: `persistence/pagination.ts#assertPersistencePage`; J2 first uses `legacyModelPage` to preserve Waterline's zero-page/unlimited forms. Named queries retain their shared existing parser. Fixed native cursor limits stay native.
- **V**: group preflight schema/default/column/callback checks plus shared `hasPersistenceTimestampMapping`, I and `inspect/ensure/requirePersistenceIndex`. Runtime composition publishes repositories only after selected mapping/index readiness, under the existing lifecycle guard.
- **NQ**: `configuration/dashboardCas.ts` and `configuration/secretLeases.ts`, shared by both selections. Dashboard CAS uses the caller's patch and clock. Secret leases use their existing BSON Date/owner fences and string `_id`.
- **NJ**: `siem/WaterlineDelivery.ts` shared claim/save/readback/ready/cleanup operations and existing eligibility predicates. Delivery save always owns `updatedAt`; model coercion is not applied. The driver enforces finite plain JSON at its boundary.
- **NF**: `figshare/NativeFigshareRepository.ts`, shared by both selections, including state validation, replace/CAS, identity, clocks, sorting and fences.
- **SA**: `storage/attachmentValues.ts` and existing `attachmentNormalization.ts`, identical service normalization used by both selectors, followed by F/T/I in the concrete physical encoder. Optional numbers deliberately retain the service's pre-existing Number-based normalization before model validation.
- **SS**: staged storage inherits the baseline's six schema methods and `recordSchemaCodec.ts`; only collection acquisition changes. Audit sanitizers remain inherited, with F/T for the physical write. Native Date fields and grant lookup remain on their existing paths.
- **C**: cache's shared `assertCacheEntryWrite`/`assertCacheEntryRecord` strict envelope and finite JSON validator on both selections. This typed cache contract accepts fewer arbitrary model writes by design; query names still use Q, generated clocks T and deletion identity I.

Every physical read validates the domain's stored shape and returns plain DTOs; read validation does not coerce corrupt stored data. JSON safety comes from the shared `assertJsonValue`; domain decoders retain their required-field/type checks.

## Harness coverage and boundaries

New R8 retained checks: 7,280 field create/patch inputs; 1,520 timestamps; 600 cross-group timestamp-flag mutations; 18 loaded model/foreign ObjectId ownership checks; 228 create/patch identity cases; 12 unrestricted/wildcard selection cases; 106 ledger values; 466 job queries; 160 ordinary R/Q/J1 queries; 648 J2 pages; 10 SIEM native pages; 6 SIEM native patches; 5 dashboard native patches; 700 attachment service inputs; 22 cache queries/clocks. The mutation matrix includes defensive loaded-shape controls; the independently validated Migration.source automatic timestamp and dontUseObjectIds examples are genuine declarations accepted by Sails loading.

The retained query suites cover 12,672 page/projection cases, 6,129 adversarial cases and 3,106 loaded baseline comparisons. Associations, exact array equality, tenant scope, producer expressions, collation/text semantics and failure-before-dispatch remain separate retained cases. Full transition fixtures cover all inventory paths, cross-writes in both directions, raw BSON, callbacks, selectors, readiness and retained-artifact rollback. Common native implementations are qualified by live contracts and both-selector tests, rather than inventing model semantics for them.

The S inventory excludes `rebindOid`, Counter and grant authorization from driver promotion: runtime explicitly forwards them to Waterline/native. `RecordRevisionMaintenance` is inventoried as bounded maintenance, not record lifecycle promotion. `WaterlineNativeStorage.ts`, GridFS byte owners/helpers and the R7 native-record array translation are unchanged from initial R8 HEAD; source hashes and the rerun GridFS/record-array fixtures qualify those regressions. No change to the gated lifecycle/identity/authorization/atomic units was made.

This is coverage of the qualified first-party programme, not evidence that arbitrary private hook overrides work on the driver. Unsupported loaded mappings must fail readiness. No performance or packed-release matrix qualification is claimed by this round.

Record-type exact wildcard selection is compared with loaded Waterline on both adapters. Explicit field lists retain the already qualified first-party DTO projection contract from reference-contract (schema:false Waterline rejects custom select clauses, so this extension is not represented as a loaded-model select comparison). The shared selection helper keeps the wildcard interpretation identical in DTO and physical projections.
