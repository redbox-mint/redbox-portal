How crosswalks work

How it fits together

  1. Source: a Figshare catalogue (institution or public) that ReDBox syncs on a schedule.
  2. Crosswalk: maps each Figshare category to a term in a local vocabulary such as ANZSRC FoR. A librarian reviews and approves it.
  3. Publishing: Figshare publishing uses approved crosswalks to set categories on articles.
