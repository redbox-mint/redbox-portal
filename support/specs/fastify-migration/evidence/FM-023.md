## Implementation and production composition

- `http/referenceRoutes.ts` holds the executable source declarations; existing Express
  exports retain object identity. `referenceReadDeclarations` derives the complete
  conversion selection. API Zod request extractors, response documentation, policy
  chains, stable targets and route collision/precedence rules remain authoritative.
- Named actions in `http/actions/{configurationReads,metadataReads,recordTypeReads,formDelivery}.ts`
  are transport-neutral. Both current Express and native controllers invoke these same
  operations through `executeReferenceRead`. Concrete controller input interfaces are
  exported from `/http`; constructors only borrow domain operations.
- The shared guard runs declared validation after host policies/CSRF and serializes
  JSON exactly once inside the action/error boundary. Native replies receive bytes;
  response schemas do not strip fields. Existing domain guards and safe error shapes
  survive, including legacy record-type 500/v2, workspace success-string errors,
  dashboard typed failures/410s, plain translation JSON and form fingerprint/prehydrate.
  URI errors remain 400 and the existing parser-style error tags retain 400/413;
  unknown faults remain sanitized 500s. Fixed diagnostics are recorded without handing
  raw failures to transport logging. Public action headers survive JSON encoding errors.
- `portalReferenceHttpInputs` selects the same initialized domains/configuration for
  both adapters. `resolvePortalInstallation` binds only the selected reference
  controllers. The native production host consumes the same frozen resolved graph.
- The retained raw differential exposed native chunked empty denials against production
  Express's `Content-Length: 0`. A production reference-route onSend hook supplies
  zero-length framing while retaining the shared boundary's owned empty stream/session/
  hooks and its original unscoped contract. Reference-route onRequest handling
  also preserves the configured HTTPS opener header before policies/parser denials;
  this is scoped by declaration identity and does not implement general page/assets.
- The FM-002 generator fingerprints the declarations, actions, production bindings/host
  and transport adapters. It derives/validates `selectedFactory` and `nativeBinding`
  for all 43 rows. Production-listener and offline tests independently assert one
  selected route/action binding per row.
