
uses `--pull=never`, so the gate does not spend the shared Docker Hub quota.
`FM039_OUTPUT` selects the receipt directory; `FM039_SCRATCH_PARENT` selects an
external scratch parent. The default cache belongs to the disposable project and
is removed on completion. `FM039_CACHE` optionally permits a caller-managed
cache. This qualification's separately owned cache is removed during final
cleanup. `FM039_SKIP_BUILD=1` is an exploration aid; the final gate builds every
source package. The historical clean-context shell entrypoint now copies its
provided archive into disposable scratch and invokes this same full gate.

`@researchdatabox/redbox-core-types` compatibility copy. It also packs the three

is renamed and authoring dependencies are merged into runtime dependencies.

the client libraries, test fixtures and development tools outside this server

Two fresh external projects install only tarballs, with strict peers, production
dependencies and lifecycle scripts disabled; each then deletes `node_modules`

## Package and declaration repairs

- Core now publishes a generated `types/` closure of its supported entrypoints.
  Explicit `@preCutover` declarations and imports used only by them are omitted;
  private Express JavaScript remains in `dist/` for the retained executable.
  Namespace, star, type-only and import-type declaration edges are traversed.
  Five regression cases cover closure traversal, private-declaration removal,
  Express rejection, missing declarations and package escapes.
- The neutral `HttpIdentity` implementation moves to authentication and is
  exported there. The old internal Express path re-exports the same class.
  Public consumers can construct the real production host without private imports.
- Explicit public return/input types prevent inferred Prisma implementation,
  Puppeteer implementation, Express-barrel and incompatible Zod JSON signatures
  from leaking into declarations. TUS storage uses the server's shared public
  `@tus/utils` contract directly, avoiding unrelated srvx environment declarations.
- Core declares pinned `@types/accepts` **1.3.7**, `@tus/utils` **0.7.1**, and the
  optional storage-hook runtime peer **1.5.3**. PDF declares its runtime `rxjs`
  **7.8.2** dependency. Dev-tools declares its Webpack wrapper's runtime input
  **5.111.1**, publishes its root declaration and removes orphan peer metadata.
  RAiD, RVA and PDF now explicitly advertise their existing root declarations.
- Browser declaration finalization resolves directory imports to `index.js`,
  including inferred `import('..')`, instead of producing `import('...js')`.
  Its orphan Node Markdown module becomes a browser re-export; no missing private
  CJS parser is referenced by browser output. The browser gate strictly compiles
  every finalized declaration and checks the historical direct parser import.
- The packed runtime exposed a Fastify-branch shutdown regression: a held HTTP
  request became an idle keep-alive connection after native transport close had
  started. The connection survived until its idle timeout and blocked stop retry.
  After owned requests and logging drain, a stopping host now reaps native idle
  connections **only after native close starts** (`server.listening` is false).
  A still-listening `preClose` phase must permit pipelined admission refusals.
  Active responses and upgraded sockets are preserved. A focused
  regression failed before the fix (**0 passing / 1 failing**) and the complete
  host lifecycle/survival gate passed afterwards (**219 passing / 0 failing**).
  After the pre-close guard refinement, all close/host/survival cases pass
  (**907 passing / 0 failing / 0 pending**), including the unchanged pipeline
  test in **6 ms** and the new idle keep-alive regression in **26 ms**.

Lock-only installs were run serially with strict peers, scripts disabled and an
external timeout. The lock audit records **no existing dependency version
changes**. The dev-tools standalone lock gains Webpack's required closure; PDF
gains RxJS's required closure. Existing local dependency metadata is refreshed.
Unrelated npm root-lock flag/deduplication churn is preserved in an artifact and
excluded from the implementation; only relevant manifest metadata and the
production `@types/accepts` flag change are retained.

The installed audit checks entrypoint/export/type targets, required peer versions,
all literal runtime/declaration imports, package containment and optional fallback
attribution. The retained optional `bcrypt` probe falls back to declared
`bcryptjs`; it is recorded explicitly. Negative controls must reject an undeclared
runtime dependency, an escaping relative import and an Express declaration.
Offline discovery forbids connections and listeners, exercises CJS/ESM/TLA, and
verifies actionable API1 refusal. The production project contains API2 hooks only.

`app.express.cjs` remains a root-only pre-cutover executable. Its private
composition JavaScript is retained inside the core tarball, with local imports
audited, but neither that executable nor private Express declarations are packed.
Core and compatibility-package export maps reject private Express/dist/source
imports. The obsolete public-Express packed-consumer fixture is removed.
