## Evidence vocabulary and execution contract

Every later result must carry one of these meanings. Do not add overlapping runs,
Bruno child requests and parent Mocha cases, assertions and test cases, or historical
results together as a single passing suite.

| Classification                 | Meaning / gate effect                                                                                                                                                                                                                      |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Fresh pass/failure             | Actually executed here; exact count and command below. A command's existence, shell syntax, or Compose render is only a static check.                                                                                                      |
| Historical baseline            | FM-001–004 and retirement results qualify their recorded source/fixtures only. Never a final-source, image, provider or Fastify pass.                                                                                                      |
| Conditional fixture omission   | A test skipped for an absent URL/service. Supply the disposable fixture and execute it; omission cannot qualify that path.                                                                                                                 |

| Required work pending          | A future task has not executed, or an existing Express runner needs adaptation. Gate remains open until fresh evidence exists.                                                                                                             |
| Environment blocked            | A required environment/input is unavailable or prohibited here. Record an alternate qualifying runner/environment or leave the requirement open; do not narrow support silently.                                                           |
| Not applicable                 | A selected configuration excludes an optional feature; pair this with qualification of its enabled profile elsewhere. No provider-required case can use this label.                                                                        |
| Outside migration scope        | Direct host TLS/HTTP2, new cross-replica continuity and mixed-version rolling operation are not added. This is a boundary, not a skipped supported test.                                                                                   |
