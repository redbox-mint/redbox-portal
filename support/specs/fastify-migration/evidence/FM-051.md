## Accepted deviations and user decisions

- The design selected v6 delivery, deferred listen, explicit API2 extension
  migration, one-time forced login with separate signing roots for cutover and
  rollback, and maintenance-window rollback to the preceding v6 build.
  [Design decisions Q1–Q26](../design.md#2-decision-record)
- Session auto-persist failure and characterized structured-input failures use
  safe HTTP responses. Logging faults expose bounded degraded state, latched
  until restart. Hook observers receive detached snapshots and ineligible
  fallbacks fail closed. Canonical Origin checks cover all Engine.IO ingress,
  and named-query parameter handling preserves configured literal semantics
  while refusing interpreted operators. [G7 deviation ledger](FM-048.md#accepted-deviations-and-recorded-decisions)
- The owner selected safe HTTP 500 for GET and HEAD when an export source
  fails before commitment, abort after commitment and before EOF, and one log
  for post-EOF disposal errors with the completed response preserved. The
  legacy absolute-form OIDC initiation differs as recorded. The owner approved
  the Angular builder's enumerated development-only Express dependency edges.
  [Stream decision](FM-024.md#reviewer-round-5--accepted-stream-failurehead-contract) ·
  [Routing deviations](FM-031.md#reported-domain-deviations--no-collision-exclusions) ·
  [Angular exception](FM-043.md#runtime-retirement-and-closure)

  2026-11-22 for this exact digest. The 100 valid r5 samples had zero errors,

## Known limitations

- The qualified portal topology is one HTTP/1.1 process with TLS termination
  at the proxy where used. G7 used disposable providers for local federation,
  storage, and integration paths. The ARM64 WSU rehearsal used local auth and
  disposable MongoDB 9.0.4, Solr, SeaweedFS and Nginx. Production federation,
  credentials, deployment config, traffic, availability and integrations
  require institution evidence. [Deployment boundaries](FM-046.md#qualification-boundaries) ·
  [Production checklist](../production-acceptance-checklist.md)
- Companion's qualified configuration uses an unlistened private Express app,
  excludes Redis and periodic pings, and requires a fresh process after stop.
  Extension hooks run in process with the documented supported registration
  surface. [Companion limits](../companion.md#process-lifetime-and-limits) ·
  [Composition scope](../design.md#41-sealed-http-composition-boundary)
- Root Mocha retained 10 pending cases. Full core had 102 pending, of which
  95 ran successfully in dedicated fixtures and seven remain checked-in skips.
  The generated reference audit retained the same 576 advisories recorded in [FM-041](FM-041.md).
  [Provider and pending accounting](FM-048.md#provider-and-pending-accounting) ·
  [Reference checks](FM-048.md#initial-fm-048-checks)
- Rollback covers the preceding v6 deployment. The two local paths establish
  transport compatibility and checkpoint recovery within the tested scope.
  Earlier v6 data transforms have their own recovery rules, and outbound
  deliveries have provider-side outcomes that survive checkpoint restore.
  [Migration boundary](../rollback-rehearsal-v6.md#migration-boundary) ·
  [External effects](FM-050.md#reconciliation-and-gate-controls)
