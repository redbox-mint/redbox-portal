## Qualification boundaries

The deployment scope is one portal process per deployment with HTTP/1.1 transport. Nginx TLS
termination is an edge capability with HTTP upstream. Direct Fastify TLS, direct HTTP/2,
multi-replica portal continuity (including PM2 cluster mode), mixed-version rolling deployment
and untested topologies are outside this qualification. MongoDB replica-set failover covers
the database tier only. Progress grants, sockets and Companion transfers require process affinity.
A stopped Companion setup starts again in a fresh process.
[Design](../design.md#11-streams-uploads-sockets-and-companion) · [Installation guide](../../../wiki/Installation-Guide.md) · [Companion process limits](../companion.md#process-lifetime-and-limits)
