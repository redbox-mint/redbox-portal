`http/progressRoutes.ts` is the neutral declaration source. Express and native
controllers delegate to the same neutral progress operations. Enabling progress
selects the complete original route set, preserving supplied declarations and
extension replacements. Actions read live request input after hooks. The six
operation placeholders and all client/transport/Companion ownership placeholders
are selected by real production handling. Runtime assertions check all **16**
progress/client/transport ownership rows and both enabled Companion HTTP rows.

One shared server `upgrade` listener selects exactly one owner. Engine.IO keeps
its retained raw-prefix matching; Companion authorizes the parsed namespace and
forwards a normalized path. Unknown paths close as on Express. Detaching either
owner leaves the other registered. The HTTP server remains host-owned.

Companion retains admitted HTTP callbacks, session persistence and transfer work
through disconnect and reconnect. Graceful drain waits for admitted work, flushes
terminal socket writes, then ends idle transports. The existing deadline still
terminates unfinished sockets/transfers and retains outstanding callbacks/pools
for an explicit stop retry.

## Process affinity and restart

See [companion.md](../companion.md). Grant issuance, Engine.IO polling/upgrades,
progress reconnect, Companion HTTP and transfer/callback sockets need affinity
to the same process. Mongo sessions do not make grants or active transfers
portable. Progress reconnect requires a fresh one-use 30-second grant. Companion
can reconnect to the same retained active transfer in that process. No new
cross-replica continuity is claimed.

Companion 7.1.1 retains process globals and a production cron without complete
public disposal handles. A full stop requires a fresh process, including after
a successful stop retry. Never reset the process guard or reuse a stopped app.
A deadline does not prove cancellation of vendor-internal remote I/O; executing
callbacks and session commits retain their dependency ownership until settled.
