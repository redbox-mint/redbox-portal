## Reading the matrix

**Preserve** means the migration target retains that supported behavior.
**Incidental** identifies an observed implementation detail, rather than adding a
new public API guarantee. Retain the characterized result during migration unless
a caller-visible change is explicitly reviewed; do not let a new router/parser
default decide it silently. Observation tests intentionally assert the existing
host, including the specific exceptions described below. Where a target differs,
port the assertions deliberately with the named migration task.

both extension-binding compositions, not the complete portal middleware setup.
L uses its own session/provider fixture, not production session ownership. These
limits avoid claiming full application/institution qualification from this matrix.
