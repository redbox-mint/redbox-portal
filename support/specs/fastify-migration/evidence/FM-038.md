  fixtures. Bundled hooks import none of these compatibility aliases.

No HTTP behavior deviation is introduced. FM-039 packed-consumer qualification,
FM-040 WSU conversion, FM-041 documentation and FM-042 executable cutover are not
claimed. Historical documentation examples remain for FM-041. The FM-002 generator now points its retained API1 route contract at the private
legacy declaration; its source-derived inventory is refreshed without changing

raw-boundary inventory is refreshed for changed source hashes/locations and the
private Companion seam; its executable ownership gate is rerun.

Exploration receipts preserve the initial missing private import, fixture type
corrections, the diagnostic assertion repair and a bundled-provider assertion
repair. The broader application typecheck found stale configuration-fixture
metadata, missing PDF/stream existence guards, an overly narrow raw-fixture route
type and a mutable preparation seam incorrectly typed readonly. These migration
branch test regressions were corrected without changing production behavior.
One FM-002 test was initially invoked with Node’s runner instead of Mocha and was
rerun with the correct runner. Two exploratory semantic type-expansion audit approaches exhausted Node's
default heap; the final declaration-graph audit avoids that expansion. An early
focused test and controller check overlapped for 17 seconds before the exclusive
runner lock was added; all later heavy commands are serialized. This was a process
deviation, not an acceptance waiver.

PDF integration exploration preserved the original assertions. The first override
used an unsupported executable configuration variable; the final environment uses
the supported `REDBOX_PUBLIC_URL`. Docker bridge traffic could not reach this
worker's published Tailscale address (`ERR_ADDRESS_UNREACHABLE`), although the host
could. The final disposable network gives the canonical MagicDNS hostname a portal
alias and uses port 49058 inside and outside the container, so Chromium and Bruno
use the same canonical URL without depending on host hairpin routing. A fresh
attachment volume is initialized to UID/GID 1000 before the unchanged node-user
entrypoint starts. An intermediate privilege-dropping entrypoint retained root's
home and failed Puppeteer configuration lookup; it was discarded in favor of a
short-lived, network-disabled volume initialization container. Diagnostic runs
stopped early after attribution are recorded with their actual nonzero exits.

## Pre-existing issues (deferred)

- Agenda's JobProcessor may retain liveness timers after a production fixture has
  closed its host, pools and request resources (also documented in FM-036/037).
  The dedicated HTTP gates run the existing source-attributing cleanup probe
  before their exit harness; full core must exit naturally. No vendor timer or
  unrelated lifecycle change is included.

- Companion’s existing process-global `node-schedule` cleanup job retains a
  `long-timeout` timer after the G2 host closes. Reproduce with G2 plus the generic
  `ownedCleanupProbe.cjs`: all 20 cases pass, network handles are empty, but the
  extra probe rejects the first `long-timeout` frame. The complete creation stack
  identifies `@uppy/companion/dist/server/jobs.js:startCleanUpJob`; every remaining
  timer is either this job or Agenda. The final G2 run uses its existing ownership
  assertions/exit harness without the additionally injected generic probe. No
  provider scheduler implementation or unrelated timer behavior is changed.

- The existing PDF Bruno Compose fixture mounts a fresh `/attachments` volume
  owned by root, while the rehearsal runtime runs as `node`. Chromium rendering
  succeeds, but staging the resulting PDF fails with `DatastreamSaveError` /
  `Cannot write file at location ...`; `/attachments` is not writable by UID 1000.
  Reproduce with the unchanged PDF Compose fixture and an uninitialized volume.
  Affects PDF attachment generation in that fixture. Qualification provisions
  ownership on its disposable volume; no Dockerfile, hook behavior or repository
  Compose change is included.
