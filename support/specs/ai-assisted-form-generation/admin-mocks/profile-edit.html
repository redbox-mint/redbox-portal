Design notes. This is the long-form app-config pattern (rail, collapsible sections with one-line summaries, sticky save bar) applied to GenerationProfileDefinitionV1, grouped by what the profile reads and what it fills. Nothing requires typing JSON Pointers or JSON Schema: source paths and target fields come from pickers over the effective forms, and the output type is derived from the chosen component. The four grounding values become a labelled scale. Validation problems appear in three places at once: the page alert (with links), rail badges and the affected row, and the disabled Publish button names the reason. Collapsed field rows summarise grounding and limits so the list stays scannable at 10–20 fields. “Preview as researcher” opens the real drafting side panel with test data.
