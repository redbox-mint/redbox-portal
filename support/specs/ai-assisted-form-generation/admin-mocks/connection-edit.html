Design notes. Choosing a provider re-shapes the form from the adapter’s getConfigurationSchema(), so admins never see an endpoint field for Bedrock (it’s derived from the region) or a secret field for the demo. The secret is a reference picker, not a password box, because secretRef is all the model stores and the design forbids secret-like keys in JSON. Data handling turns dataPolicy into four plain questions and a verification checkbox. Test sits beside the form, follows the existing unsaved-draft test pattern and lists each check separately so a failure says what to fix.
