Design notes. Picking the profile first pre-sets the source and target record types, removing the most common binding mistake (a mismatch with the profile’s source slot). Each section heading answers one question: what researchers see, where, what it creates, who. The live preview shows the button in place, the hint tooltip and the audience. sourceValueMappings are framed as “copy values without AI” because that’s the distinction admins care about. Server validation results (/bindings/:id/validate) are listed as checks beside the preview.
