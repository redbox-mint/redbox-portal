Requirements:

- Node.js `26.11.1` and npm `11.20.0` for the current development branch. Run
  `nvm install && nvm use` from the repository root, then check `node --version`
  and `npm --version`. Released v5 comparison artifacts use their own supported
  runtime; do not require Node 26 to run an old release.
- Docker and Docker Compose

We recommend using a VM provisioned via Vagrant for a seamless development environment. This includes all necessary tools. Access this through our [Vagrant repository](https://github.com/qcif/vagrant-redbox-dev).
